## 🛠️ How to Compile & Run

To run these programs locally, ensure you have a C++ compiler installed (such as GCC/MinGW or Clang).

### Compiling via terminal
Open a terminal in the folder containing the C++ file and run:
```bash
g++ -std=c++17 <filename>.cpp -o output
```

### Running the binary
*   **Windows**:
    ```bash
    .\output.exe
    ```
*   **Linux / macOS**:
    ```bash
    ./output
    ```
